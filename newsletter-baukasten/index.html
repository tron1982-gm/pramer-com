So geht's

  1. Optional: oben eine Vorlage laden.
  2. Felder links ausfüllen und Bausteine hinzufügen – die Vorschau rechts aktualisiert sich sofort.
  3. Rechts auf „Ganze E-Mail kopieren" klicken.
  4. In Outlook eine neue Nachricht öffnen, in das Textfeld klicken.
  5. Mit Cmd + V (Mac) bzw. Strg + V (Windows) einfügen.
  6. Betreff, Empfänger prüfen, ggf. Text noch direkt in Outlook feinjustieren, dann senden.
Hinweis: Web-Schriften und feine mobile Anpassungen werden beim Einfügen in Outlook nicht immer übernommen – das Layout bleibt aber stabil und markenkonform (Navy/Gold, Tabellen-Aufbau). Vor größeren Aussendungen: kurz eine Test-Mail an dich selbst schicken und auf Handy und Desktop prüfen.

Vorschau entspricht 1:1 dem, was kopiert wird.
